# CodeAlpha_EDA

## Exploratory Data Analysis of Superstore Sales Data

### Project Overview
This project explores Superstore sales data to identify sales trends, category performance, regional profitability, missing values, and potential outliers.

### Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- SciPy
- Google Colab

### Tasks Performed
1. Inspected dataset structure and data types.
2. Checked missing values and duplicate records.
3. Created visualizations for category sales, regional profit, monthly sales trends, and profit distribution.
4. Tested differences in average profit across regions using ANOVA.
5. Examined the correlation between sales and profit.

### Key Findings
- Technology has the highest total sales among the three product categories.
- The West region has the highest total profit.
- ANOVA found a statistically significant difference in average profit across regions at the 5% significance level (p = 0.048892).
- Sales and profit have a moderate positive correlation (r = 0.4791, p < 0.001).
- The dataset contains 11 missing Postal Code values and 1,871 negative-profit records.
